# GATE DA 2027 Prep

Study app built from all GATE Data Science & AI papers so far (2024, 2025, 2026): 195 questions with official answers, worked solutions, topic tags, a weightage analysis, beginner notes for each subject, and a 13-week roadmap to the exam (6 Feb 2027).

## Run

```bash
npm install
npm run dev        # http://localhost:3000
```

## Pages

| Route | What |
|---|---|
| `/` | Analysis: marks by subject and year, topic priority ranking, topics never asked |
| `/roadmap` | 13-week plan (weeks allocated by marks, ordered by dependency), tick topics off |
| `/subjects/[slug]` | Learn: the subject's topics in study order, each with a one-line summary |
| `/subjects/[slug]/[topic]` | Full beginner notes (big idea, intuition, key terms, each formula explained, 3+ examples, common mistakes, self-check), plus that topic's formulas and past questions |
| `/formulas`, `/formulas/[slug]` | Clean formula sheets for quick revision (printable) |
| `/questions` | Filter and solve all 195 questions. Attempts are saved in the browser |
| `/questions/[id]` | Attempt → "How to think" hint (intuition + formulas explained) → check → full solution, plus the original paper page image |
| `/syllabus` | Official 2027 syllabus with each topic's marks |
| `/papers` | Original PDFs (papers, keys, syllabus) |

## Data

- `../analysis/questions/*.json`: extracted, solved and tagged questions (source of truth)
- `npm run data`: merges them into `src/data/questions.json` (runs automatically before `build`)
- `node scripts/check-math.mjs`: checks every LaTeX snippet with KaTeX
- `python ../analysis/check_keys.py`: checks every answer, type and mark against the official keys
- `../analysis/intuition/<slug>.json`: the beginner hint for each question, merged in by `npm run data`
- `src/content/formulas/<slug>.md`: formula sheets (same `## <Topic>` rule)
- `src/content/learn/<slug>.md`: subject notes. Each `## <Topic>` heading must match the topic name in `src/lib/taxonomy.ts`

Answers come from the official keys (all 195 cross-checked). Solutions and tags were generated by AI. One question (2024 Q14) is flagged as ambiguous.
